# HERO Recruiter — 波总结构化面试工作流

## 核心方法论

**PCQ-24 HERO 心理资本模型**替代 MBTI：
- **H-Hope（自驱力）**：遇到死胡同是找替代路径还是抱怨
- **E-Efficacy（自我效能）**：面对陌生任务是"我能拆"还是"需要帮助"
- **R-Resilience（韧性）**：被彻底否定后恢复速度
- **O-Optimism（归因）**：复盘时归因"这个环节没设计好"（客观）还是"我不行"（自我攻击）

## 完整工作流

### 第一轮：15min HERO高压快筛（手机/视频）

3个标准场景题（所有候选人统一），每题带3层追向。面试官只问不记，全程录音。

**场景1 (H-Hope + 工作闭环)**：
"讲一次你手头项目彻底卡死，别人都觉得没戏了。当时卡在哪里？"
→ 追问 Plan B → 追问结果和进度同步

**场景2 (R-Resilience + O-Optimism + 反内耗)**：
"讲一次全力以赴但被彻底否定的经历。对方最狠的一句话是什么？"
→ 追问恢复周期 → 追问根本原因归因

**场景3 (E-Efficacy + 对外能量)**：
"如果入职第一周给你一张完全陌生的资方名单，没有任何引荐，让你明天出初步接触报告——今晚怎么过？"
→ 追问被拒后的反应 → 追问过往类似经历

**评分**：面试后录音转文字→交AI按HERO+对外+静功6维评分(1-5)→出结构化报告→合伙人决策

### 第二轮：线下终面（通过线上快筛者）

必做两个场景，重点观察微表情：

**场景A：多任务冲突排序**
5件事同时压过来，看是否区分"重要紧急"vs"紧急不重要"，是否敢于向上沟通。

**场景B：不合理批评的微表情**
面试官突然冷脸："你刚才的回答让我很失望。"
→ 看5秒内的情绪调节：争辩(低R) / 蔫了(低R+低O) / 冷静追问(高R+高E)

### 第三轮：合伙人终面

业务深度+文化匹配，由合伙人主导。
