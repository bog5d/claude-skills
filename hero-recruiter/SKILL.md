# HERO Recruiter — 波总结构化面试工作流

## ⚠️ 铁律：先 grillme，再执行

**任何招聘任务，必须先 grillme 盘清思路再出稿。** 不要假设你知道用户要什么——问出来。

具体：直接应用 `grillme` 技能，至少走两波，确认：
- 核心目标（选人 vs 筛人 vs 感受市场）
- 判断机制（直觉 vs AI，直觉锚点是什么——节奏/眼神/第一反应？）
- 最大恐惧（漏掉/走眼/浪费时间/合伙人不同意？）
- 决策流程（面完当天定 vs 等AI报告 vs 合伙人先筛？）

详见 `references/grillme-recruitment-insights.md`。

## ❌ 禁止产物

- 不要出"面试执行手册"——太厚，没法上场前看
- 不要出"方法论教科书"——那是给HR写的，不是给面试官写的
- 不要出"评分量表"——面试中不打分不记笔记，后面AI做

## ✅ 唯一交付物：面试沟通卡

**每张卡 = 一页。面试前5分钟扫一眼，拿着就能走全程。**

### 卡片结构（4块）

1. **📋 关键背景**（3行）：姓名、学历、最硬的一段经历
2. **🔍 简历疑点**：进场前就知道哪里容易有坑
3. **💬 面试切入**（3个自然问题）：顺着对方回答走，不跳场景
4. **⚠️ 红旗**：一句话，触发就直接降分/加速收尾

### 卡片设计原则

- **不是为了"问什么问题"，是为了"制造什么情境逼出真实反应"**
- 波总的直觉锚点是**节奏**——太快像背稿、太慢像编造、刚好是真实思考。问题不能是可以提前准备的标准题
- 追问不可预测——卡上只写切入点和转向触发器，不写完整对话脚本
- 前三候选人深度模式，后六带快速pass开关（3分钟内触发红旗→10分钟收工）

### 卡片时间排序

按面试排程顺序排列，每张卡标注时间槽。

## 决策流程（grillme中确认的标准流程）

```
面试(20min/人) → 全程录音 → AI HERO分析 → 合伙人先看报告筛选 → 波总二面 → 合议拍板
```

AI报告是给合伙人看的，面试卡是给波总看的——两者受众不同，不能混用。

## 关键教训：面试设计前必须 grillme

不要直接出面试题或沟通卡。先走 grillme 挖出波总的：
- 直觉锚点（他面人时到底听什么——节奏？眼神？第一反应？）
- 最大恐惧（怕漏掉？怕看走眼？怕浪费时间？）
- 决策流程（谁先看报告？合伙人参与吗？）
- Kill Criterion

这些决定了面试卡的设计方向。不问清楚就出卡 = 大概率白做。
