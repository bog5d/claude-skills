# 面试沟通卡模板

## 格式规范

每张卡一页。四个区块，用分隔线隔开。字体 10pt，留白足够。

```
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
🕙 时间槽    姓名    性别 · 年龄 · 学历简称
     JD排名 · 分数
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

📋 关键背景（3-4 条要点）
· 最硬的一段经历（一句话）
· 量化业绩（如果有）
· 证书/技能亮点
· 学历亮点（如果有）

🔍 简历疑点 / 待验证（1-2 条）
· 最需要确认的矛盾或模糊点

💬 面试切入（3 个自然问题）
1. 破冰切入——从最近经历或最亮眼经历自然切入
2. 深挖追问——顺着第 1 个问题往"困境/失败"方向引
3. 情境测试——抛一个跟岗位强相关的陌生场景

⚠️ 注意：一句话红旗信号

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

## 设计原则

1. **不是为了"问什么"，是为了"制造什么情境"**
   - 问题不能是可提前准备的标准题
   - 追问不可预测——卡上只写切入点和转向触发器

2. **节奏优先于内容**
   - 波总的直觉锚点是回答的节奏感，不是答案本身
   - 卡上的追问设计应该逼迫候选人脱离背稿模式

3. **快速 pass/fail 机制**
   - ⚠️ 红旗如果在前 3 分钟触发 → 10 分钟收工
   - 适用于后段候选人，不适用于前三

4. **不是对话脚本**
   - 卡上写的是"从哪切入"和"往哪引导"
   - 不写完整对话，不写标准答案预期
