# 企业深度尽调（Corporate Due Diligence）

## When to Use

- 波总要摸清一家公司底牌：合作谈判前（中材矿院案例）、供应商/客户背景、投资标的分析
- 目标公司常有集团/母子公司链（如中材矿院→中材矿山→中材国际600970→中国建材），需要穿透

## 核心流程（波总铁律版）

1. **框架先行**：套用仓库模板 `Cangjie_OBS_Notes/知识库/调研框架/企业深度尽调框架.md`（12 维度：基础身份/业务/产品/技术/团队/市场/空间/估值/痛点/行业素材/谈资故事/信息源+报告规范）。首次用后框架已入库，直接引用。
2. **派 Cursor CLI 执行搜索+报告**（波总铁律：搜索/分析类任务"务必使用 Cursorcli 来干"，Hermes 只做总调度+进度通报）：
   - 写自包含 exec prompt：目标公司+背景（为什么尽调，服务于什么决策）+搜索方法（curl 官网/搜索引擎 HTML/百科/财经F10/工商聚合页）+**铁律**（禁止编造、每条数据带来源+日期+可信度、冲突并列、查不到标"待核实"）+输出路径（`~/.hermes/cache/documents/`）+完成标准
   - 后台执行：`cursor-agent -p --yolo "$(cat /tmp/xxx/exec_prompt.md)"` + `notify_on_complete=true`
   - 报告入 `~/.hermes/cache/documents/`（不入仓库；框架入仓库）
3. **独立验证（不可跳过）**：子代理自报不可信。必须亲自核验 3+ 关键数字：
   - 工商（成立时间/法人/注册资本）、上市主体（代码/市值/股价×股本≈市值）、财务（营收/净利，对比年报口径）、高管（董事长/董秘）
   - 抽查其新引入的外部事实（如"2025-09 与某公司签战略合作"）——web_search 确认主体真实存在
   - 内部材料交叉验证：对方内部口径（群聊/文件）与外部尽调结果互证=尽调可信度上档（本会话：中材张部长"400矿山"原话 ↔ Cursor 尽调报告完全咬合）
4. **交付**：报告文件（MEDIA:）+ 消息摘要：3 条最值得记住的决策信息 + 3 个待核实缺口 + 关键底牌表（谈判弹药）。

## 报告规范（写入框架第 11-12 节，执行时强制）

- Markdown，表格优先；数字必带来源+日期；口径冲突并列呈现（如官网 3200 人 vs 招聘站 5000 人）
- 查不到=如实写"未公开/待核实"，禁止编造（本会话 Cursor 对矿院单体营收/实缴诚实标"未公开"，这是对的）
- 结尾固定：3 条最值得记住的信息 + 3 个待核实问题
- 区分"目标公司 vs 母子公司数据"：矿院单体未披露时用母公司/集团口径并明确标注"不可直接外推"

## 穿透技巧（识别关键路径）

- 语音转写/口述的机构名先怀疑 ASR 错误："一保研究院"→实际=中材（南京）矿山研究院。三要素验证法：地名+行业+机构类型唯一命中（南京+矿山+研究院）
- 官网友情链接/子公司列表=穿透捷径（sinoma-mc.com 首页直接列出四大区域公司+研究院）
- 上市公司年报"主要子公司"表=子公司财务数据的公开唯一来源（600970 年报列中材矿山营收/净利/净资产）
- 关键数字与口述对账："全球400个矿区客户" ↔ 中材体系"近400座矿山在运营"——内部原话是最终验证

## 交付后动作

- 尽调结果回写仓库：entities（ORG/PRJ 增量）、relations、拆解卡（若关联素材）、待办（谈判/申报行动项）
- 波总要的"初步框架"→ 入库 `知识库/调研框架/`（可复用资产）
- 谈判要点提炼：对方角色定位（供应商/技术入口/决策链）、我方卡位（别沦为可替换设备商）、待核实清单（财务/立项/排他）

## 失败模式

| 症状 | 原因 | 修法 |
|------|------|------|
| 子代理报告数字失真 | 自报不可信 | 亲自核验 3+ 关键数字再交付（波总铁律） |
| 报告堆砌无决策意义 | 缺背景 | exec prompt 必须写清"为什么尽调、服务什么决策" |
| 估值/订单口径离谱 | 立项≠订单 | 区分"目标值"vs"承诺"（刘培福"产值目标为努力目标"）；课题清单≠确定订单 |
| 机构名对不上 | ASR/口述错误 | 三要素唯一命中法 + 向内部人确认（群聊/会面直接问最快） |
