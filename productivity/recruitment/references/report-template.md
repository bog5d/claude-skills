# 评估报告模板

## 报告结构

### 封面
- 标题：{岗位名称} 候选人评估报告
- 日期：YYYY-MM-DD
- 候选人总数：N
- 评估工具：Hermes Agent

### 第一节：评估模型说明
- 维度权重表（含 JD 原文对应）
- 判定标准说明

### 第二节：核心结论
- 梯队分布（强推/推荐/备选/不推荐数量）
- 整体特征判断

### 第三节：逐人详析（≥阈值分）
- 基本信息（姓名、性别、年龄、联系方式）
- 教育背景（原文引用）
- 工作/实习经历（原文引用 + 量化业绩）
- 项目经历（原文引用）
- 证书与技能
- 6-8维评分表（维度/得分/依据）
- 综合评价（1-2句话）

### 第四节：低分简表（<阈值分）
- 仅表格，无详析

### 第五节：综合排名总表
- 排名/姓名/得分/推荐等级/核心竞争力/短板风险

### 第六节：面试与录用建议
- 第一优先级（详述面试关注点）
- 第二优先级
- 第三优先级
- 整体判断

## 格式规范
- 中文排版，SimSun/PingFang SC
- 表格用 Light Grid Accent 1 样式
- 表头深蓝背景 (#2F5496) + 白色加粗字
- 前3名行浅绿高亮 (#E2EFDA)
- 页脚灰字标注生成时间
