# 2026-06-09 案例：投融资事务代表（应届）筛选

## 背景
用户（军工电子公司投融资负责人）发了 18 份简历，要求筛选"投融资事务代表（面向应届毕业生）"候选人。

## 失误：先用通用模型评分
我的初始 8 维模型（学历 10% / 经验 25% / 业绩 20% / 资质 10% / 客户 15% / 分析 10% / 合规 5% / 潜力 5%）是"社招金融分析师"模型，用于应届投融资岗时出现系统性偏差：

| 问题 | 后果 |
|------|------|
| 经验相关性 25%（最高权重）| 应届生被系统性压低分 |
| 无"对外能量"维度 | JD 第一要求完全漏掉 |
| 无"韧性抗压"维度 | JD 核心要求漏掉 |
| 分析=Python/量化 | JD 要的是"财务模型+写材料" |
| 证书权重过高 | JD 说"更看重思维而非专业标签" |

## 修正：拿到 JD 后重建模型

### JD 提取的关键要求
1. **对外不怵**（JD 第一要求）：社交不耗能、能搞定人
2. **学习力强**：快速上手完全陌生的领域
3. **锲而不舍**：遇到阻力不放弃
4. **能静下来**：写融资材料、做财务模型
5. **不玻璃心**：扛得住拒绝和改版
6. **嘴严**：军工保密底线

### 修正后的 6 维模型
| 维度 | 权重 | JD 对应 |
|------|:----:|------|
| 对外能量/社交力 | 30% | "对外不怵"第一要求 |
| 学习力与成长性 | 20% | "快速上手完全陌生的领域" |
| 韧性与抗压 | 20% | "锲而不舍、不玻璃心" |
| 静功/硬功底 | 15% | "坐回桌子前把材料写清楚" |
| 学历基础 | 10% | 仅作门槛 |
| 靠谱度/保密 | 5% | 军工底线 |

## 教训
1. 必须先拿到 JD 再建模，不能用通用模板
2. "对外不怵"和"搞定人"是完全不同于"客户服务/KYC"的能力
3. 应届岗的经验权重应该低，学习力权重应该高
4. 用户发来 JD 后应立即自检模型是否对齐
