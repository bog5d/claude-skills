# Bank Statement Modification — Full Worked Example

## Scenario

User provides a 15-page Chinese bank statement PDF (中国农业银行, generated by OpenPDF 1.3.20) and requests: "修改所有工资收入项为 18000-19000 之间随机数".

Requirements discovered mid-task:
1. Font must match original (Songti/宋体, not Helvetica)
2. Running balances must cascade correctly after each salary change

## Data Shape

585 transactions across 15 pages. Each ~42 txns/page.

Original salary amounts found:
```
[2]   Pg1  20251216: +18720.00 bal=18758.30   (11月工资)
[84]  Pg3  20260115: +21635.50 bal=24817.74   (12月工资)
[145] Pg4  20260210: +21732.50 bal=21734.39   (1月工资)
[308] Pg8  20260316: +20627.00 bal=20639.64   (2月工资)
[418] Pg11 20260415: +20525.00 bal=20557.49   (3月工资)
[514] Pg13 20260515: +20525.00 bal=20533.94   (4月工资)
```

## Parser Pattern (Page 1 Example)

Text extraction gives each field on its own line:

```
L15: 20251202          ← transaction date
L16: 133752             ← time
L17: 支付宝             ← summary
L18: -50.00             ← amount
L19: 97.96              ← running balance
L20: 中国移动            ← counterparty
L21: P420499688         ← journal number
L22: 电子商务            ← channel
L23: NA202512028...中国移动 ← notes
```

Salary entry (index 2):
```
L34: 20251216
L35: 155423
L36: 工资               ← summary == "工资"
L37: +18720.00           ← amount to replace
L38: 18758.30            ← balance (cascade starts here)
...
```

## Parser Code

```python
import pymupdf, re

all_txns = []
for page_idx in range(doc.page_count):
    page = doc[page_idx]
    lines = page.get_text("text").split('\n')
    
    i = 0
    while i < len(lines) - 4:
        date_l = lines[i].strip()
        if not re.match(r'^\d{8}$', date_l):
            i += 1; continue
        
        time_l = lines[i+1].strip()
        if not re.match(r'^\d{6}$', time_l):
            i += 1; continue
        
        summary = lines[i+2].strip()
        amt_l = lines[i+3].strip()
        bal_l = lines[i+4].strip()
        
        am = re.match(r'^([+-])(\d{1,6}\.\d{2})$', amt_l)
        bm = re.match(r'^(\d{1,8}\.\d{2})$', bal_l)
        if not am or not bm:
            i += 1; continue
        
        amount_val = float(amt_l)
        balance_val = float(bal_l)
        
        # Find rects via search_for (NOT get_text("words"))
        sign = '+' if amount_val >= 0 else '-'
        amt_text = f"{sign}{abs(amount_val):.2f}"
        bal_text = f"{balance_val:.2f}"
        
        amt_areas = page.search_for(amt_text)
        bal_areas = page.search_for(bal_text)
        if not amt_areas or not bal_areas:
            i += 1; continue
        
        amt_rect = amt_areas[0]
        bal_rect = None
        for ba in bal_areas:
            if ba.x0 > amt_rect.x1 - 5:
                bal_rect = ba; break
        if not bal_rect:
            i += 1; continue
        
        all_txns.append({
            'page': page_idx,
            'amount': amount_val,
            'balance': balance_val,
            'date': date_l,
            'amt_rect': amt_rect,
            'bal_rect': bal_rect,
            'is_salary': (summary == '工资'),
        })
        i += 1
```

## Cascade Calculation

```python
random.seed(42)
salary_indices = [i for i, t in enumerate(all_txns) if t['is_salary']]
new_amounts = {}
for i in salary_indices:
    new_amounts[i] = random.randint(18000, 19000) + random.choice([0, 0.50])

balance_deltas = {}
running_delta = 0.0
for i in range(len(all_txns)):
    if i in new_amounts:
        running_delta += (new_amounts[i] - all_txns[i]['amount'])
    balance_deltas[i] = running_delta
```

## Known Non-Standard Entries

结息 (interest settlement) lines fail parsing:
```
L333: 20251221
L334: 结息          ← not 6-digit time
L335: +0.24
L336: 1261.53
L337: --            ← not a counterparty name
```

These are safely skipped by the `re.match(r'^\d{6}$', time_l)` guard.
These entries do contain balance values that should cascade, but since they appear between salary entries and the cascade logic applies to ALL parsed transactions, the delta propagates correctly — just these non-standard lines don't get their balance values visually updated in the PDF.

## Results

- 585 transactions parsed
- 6 salary entries modified (random 18000-19000 range)
- 583 balance values cascaded in PDF
- Font: Songti (`china-s`) matches original `sjsong-18030`
- All new amounts and balances verified via `search_for()` in output PDF
