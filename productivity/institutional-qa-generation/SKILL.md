# Institutional Q&A Generation — 机构问答口径生成

从公司原始资料（录音转录稿、会议纪要、技术文档、散乱笔记）中提取核心技术/业务观点，生成面向投资机构的结构化问答口径文档。

## 核心原则

1. **口径必须基于真实素材** — 从内部录音/纪要/文档中提取，不可凭空编造
2. **区分内外语境** — 内部讨论的口语化表达 → 外部需要精炼的专业表述
3. **层次化输出** — 电梯演讲（30秒）→ 标准问答（2分钟）→ 深度追问（5分钟）

## 工作流

### 第一步：收集原始素材
搜索以下位置：
- `~/.hermes/adjutant/repo/hermes-adjutant/` — 副官系统中的所有文件
- `/Users/mac/Documents/交付给团队_最终版/` — 标准素材库
- `/Users/mac/.hermes/cache/documents/` — 历史缓存文档
- 用户本次对话中提供的文本

搜索关键词：技术术语、产品名称、核心概念、业务模式。

### 第二步：提取核心观点
从原始素材中逐条提取：
- **定义**：XX是什么（1-2句话）
- **区别**：XX vs YY（对比维度）
- **壁垒**：为什么别人做不了（3-4个维度）
- **数据**：营收/利润/增长率/市场份额
- **案例**：具体产品/客户/应用场景

### 第三步：构建问答口径
输出结构（参考 `references/qa-template.md`）：

1. **一句话定义**（电梯演讲，30秒）
2. **核心问答**（3-5组Q&A）
3. **常见追问应对**（预判机构可能追问的方向）
4. **关键数据速查表**（随时可以引用的数字）

### 第四步：交付
保存到 `~/.hermes/cache/documents/{公司名}_{主题}_机构问答口径.md`

## 输出格式规范

- 使用中文，面向机构投资者的专业语气
- 避免内部黑话和缩写（除非附带解释）
- 每个答案控制在 2-4 句话，便于口头传达
- 关键数据必须标注来源（录音/文档/日期）
- 护城河分析必须从真实能力出发，不可夸大

## 陷阱

1. **不要编造数据** — 如果素材中没有某个数据，标注"待确认"而非编造
2. **不要过度简化** — 机构问"算力vs处理"不是要字典定义，而是要你公司的差异化定位
3. **区分"是什么"和"为什么重要"** — 口径不仅要定义概念，更要说明为什么这个概念对公司估值有意义
4. **录音转录稿中的口语化表达** — 需要提炼为书面语，但不要改变原意
