# Cursor 拆解 prompt 结构 + 输出模板

## Cursor 派活 prompt 必备六段

```
# 任务：N 份会议/路演录音转写的"团队盲区与对齐诊断"

你是波总（XX公司投融资负责人）的拆解助手。波总没有参加这些会议，是公司团队去跑的。
波总要的产出不是归档，而是洞察：团队知识盲区、波总不知道的新信息、团队对外表述与
既定口径不一致的地方、团队说了波总没拍板的事。

## 输入文件（N 份，均为粗糙 ASR 转写，错误密度高）
<逐行列出绝对路径>

## 背景知识（必须知道的上下文）
<公司是谁/创始人/波总角色/当前融资主线>

## ASR 已知高频错误（转写中的人名/机构名可能长这样）
<正确 → 错误变体 对照表，从 references/asr-term-dictionary.md 复制并改机构名>

## 公司既定口径对照表（团队表述若与此不符=口径偏差，重点抓）
<定位句/叙事结构/财务多版本/收入结构/对赌节点/战略主线关键词>

## 每份文件的输出（写一个 md，路径 <analysis_dir>/）
文件名：<原名>.分析.md，结构：
1. 会议信息：机构名（对照背景识别）、场景、日期、我方/对方出席人
2. 说话人识别：每人编号+推测身份+置信度（高/中/低）+依据
3. 新增信息（波总可能不知道的）：每条一句话，涉及人名/机构/数字标[待确认]或[已对照确认]
4. 口径偏差：原文摘录 vs 既定口径，逐条表格
5. 团队盲区：卡壳/含糊/答不上/转移话题的点 + 需要波总补什么
6. 承诺与风险：说了公司没拍板的事 + 其他风险（敏感信息/口径不统一）
7. 待波总确认：最需要波总回答/决策的问题（最多5个）

## 最终汇总输出（<analysis_dir>/00_汇总诊断报告.md）
1. 横向共性问题（多份共同出现=系统性问题，重点）
2. 团队能力画像（谁在对外讲、讲得怎样、格局好vs差）
3. 最需要波总补位的前5件事（按紧急排序）
4. 信息补全清单（跨文件去重）
5. 与战略主线的未对齐点（团队讲的 vs 波总定的）
6. 建议动作（3-5条可执行）

## 铁律
- 禁止编造：ASR 无法确认的人名/机构/数字一律标[待确认]
- 引用必须带原文摘录（短句），不要只给结论
- 全程中文输出
- 最后在终端打印"ALL DONE + 输出文件清单"
```

## 启动命令（实测可用）
```bash
mkdir -p <analysis_dir> && cd <work_dir> && \
cursor-agent -p --yolo "$(cat /tmp/prompt.md)"   # terminal(background=true, notify_on_complete=true)
```

## 分场分析 7 节（每份文件）
会议信息 / 说话人识别 / 新增信息 / 口径偏差 / 团队盲区 / 承诺与风险 / 待波总确认

## 汇总诊断 6 节
横向共性问题 / 团队能力画像 / 补位前 N 件事 / 信息补全清单 / 战略未对齐 / 建议动作
