# 债务转移 + 来时路备注 操作参考

> 基于 2026-07-05 石墨同步 + 二爸清零实战记录

## 债务转移的数学

当一笔债务被清偿且资金来自多个源头时：

```
二爸债务 ¥20,000
  ├ 波总自还: ¥10,000  → 总债务净减少
  └ 妈妈代垫: ¥10,000  → 债务从二爸转移到妈妈

总债务净变化 = -¥10,000（仅自还部分影响总额）
妈妈债务 = 原额 + ¥10,000（代垫是新增债）
```

```
YYYY/MM/DD <事件描述>
YYYY/MM/DD <事件描述>

```

## 校验公式

- `grand_total_change = -self_paid_amount`
- `total_cleared_change = +total_debt_amount`
- 代垫方的 `amount_change = +proxy_amount`
- 代垫方的 `notes` 必须标注「代垫给XX」来源
