# 对外正文标准结构

## 标题格式

`关于公司[核心技术名称]技术、知识产权及产业化能力的说明`

## 第一部分：核心结论（3-5段）

用最精炼的语言直接回答投资人最关心的核心问题：

1. XX 不是单一通用芯片/单一器件（定义澄清）
2. 公司掌握完整技术体系和核心参数（能力声明）
3. 底层技术权益已依法取得（权属声明）
4. 外部供应商和高校承担非核心工程化工作（依赖边界）
5. 公司已经完成国产化供应链和产业验证（交付能力）

## 第二部分：技术构成说明

- 由哪些部分组成（器件、结构、参数、封装、系统适配等）
- 技术价值在哪里（不是单一器件壁垒，是系统级能力）
- 首次出现关键概念时给出清晰定义

## 第三部分：知识产权及技术来源

不堆专利号。按层次分组：

1. 底层技术或系统结构层
2. 器件和阵列结构层
3. 封装与工程化层
4. 公司后续改进和应用层

专利信息不完整的，保留核验提示：`【内部核验：请法务确认后删除】`

## 第四部分：半导体器件与供应链

- 器件由专业供应商生产（正常产业分工）
- 公司掌握：技术指标、选型、组合、结构、封装、验收
- 早期国际器件验证 → 后续国产化 → 当前供应状态
- 不依赖单一境外供应商

## 第五部分：外部合作边界

- 外部单位（高校/供应商）承担什么工作（制图、仿真、样件、适配等）
- 外部单位不掌握什么（完整方案、关键参数体系、阵列拓扑、工艺窗口、验证数据库）
- 上述结论必须建立在公司真实管理措施基础上

## 第六部分：核心技术人员及组织化沉淀

- 关键人物的核心贡献
- 公司如何通过团队、文件、专利、工艺标准、数据库完成组织化沉淀
- 避免"全部技术存在于某个人头脑中"的印象

## 第七部分：投资机构核验方式

可提供的文件清单：

1. 技术转让协议
2. 专利证书及法律状态
3. 专利权属变更文件
4. 核心技术和产品对应关系表
5. 国产器件测试报告
6. 供应商准入及备选供应体系
7. 第三方测试报告
8. 客户验证或产品交付证明
9. 研发、工艺和验收文件目录
10. 核心人员保密、职务成果和知识产权归属文件
