# 对外材料多角色流水线（波总 2026-08-19 固化）

## 触发条件

波总要求生成任何**对外交付文档**：项目背景说明、BP、机构答复口径、合作方案、尽调材料、政府汇报等。
铁律：**不要让一个 AI 自己想、自己审**——多角色独立上下文交叉验证，防自我审查偏差（波总原话）。

## 角色定义（4 个，各司其职，互不偷看）

| 角色 | 职责 | 输出 |
|---|---|---|
| ① 素材收集员 | 只讲"有什么"：全库 grep + 精读，事实带来源（文件路径+SRC+日期），事实/推断分开，[待确认]标注 | 素材包（分节+金句+缺口） |
| ② 对方视角模拟员 | 只讲"对方想看什么"：站在读者立场列想看清单（按优先级）、可模糊点、雷区清单（含穿帮后果）、呈现顺序 | 视角分析文件 |
| ③ 整理员 | 只讲"怎么呈现"：基于①②合成正式文档，**不新增事实、不编数字** | 成稿 docx+pdf |
| ④ 创始人审读员 | 模拟波总/公司创始人视角审读初稿（见审读清单），输出收敛意见 | 审读意见 → 驱动 V2 |

## 执行流程

```
阶段0 任务理解：确认读者对象（引导基金/国资/产业方？）、保密边界、主线叙事
阶段1 并行×2：① 素材收集员 + ② 对方视角模拟员（delegate_task batch，完全独立）
阶段2：③ 整理员合成 V1（读①②产出，口径纪律执行）
阶段3：④ 创始人审读员审 V1 → 收敛意见（波总亲自审时=最高优先级输入）
阶段4：修订 V2（按审读意见收敛披露、聚焦主线）
阶段5 监工验证：文件真实存在/可打开/敏感词反查/格式铁律 → 交付
```

执行引擎：任务启动先走 Cursor CLI（🔴）；三角色独立用 delegate_task（波总明确要求多角色时）；Hermes 全程监工验证（不信子代理自报）。

## 创始人审读清单（波总 2026-08-19 三个维度，每次必查）

1. **披露收敛**：数字是否必要？工程细节（技术指标/单价/成本明细/拨投上限）→ 删；只留大叙事（市场空间/场景/愿景）。"家底全亮"是压力不是诚意。
2. **业务聚焦**：新主体/新项目必须写成**主线的场景延伸**，禁止读成"什么都在做"。话术："依托母公司 X 能力，面向 Y 场景的 Z 平台"——全篇贯穿"一根主线、多个场景"。
3. **股东结构简化**：未注册主体只写控股方+团队比例（如"泽天控股 51% + 核心团队 49%"），团队份额=激励与绑定，里程碑后现金换股逐步吸纳进集团。**不写**：多方明细、个人持股、5%池子、实缴细节、代持、薪酬。
4. **抽象加滤镜**：用"产业拼图/场景卡位/主线延伸/生态协同"类表述；未定事项写"愿与合作机构所在地对齐"这类开放性表述，把硬伤变筹码。

## 资本市场叙事纪律（波总 2026-08-19 追加，三大原则）

1. **去军工化**：资本市场对军工评价 2024-2026 大幅走低，投资人视角=黑名单风险。对外材料**第一时间讲公司本质**（端侧算力+底层实时操作系统，反复强调），军工只作技术可信度背书（全文 ≤2 次），用"高可靠/强实时/严苛环境验证"表述替代"军工级"。公司名含"雷达"等军工色彩字眼时标注拟用名，正文不渲染。
2. **挂靠投资人热点**：2026 一级市场热点=AI/算力/具身智能/机器人/商业航天（吸金超70%、国资密集入场、人民币基金主体=地方政府引导基金）。叙事公式：端侧算力+RTOS=**AI 场景落地的底座**（机器人/低空/无人化必装层），当前场景=已验证的第一批落地，未来延伸=具身智能/低空等热点——与资本热点同频，不孤立讲行业。
3. **去导演感（元叙述清零）**：全文必须是会议桌自述口吻——"这是我们的规划"，像当面跟对方说话。禁止出现设计逻辑/引导意图的元叙述，如"对投资人而言，判断标准只有一条""场景可以增加，主线不能偏离""本说明旨在供投资决策参考"类句子全部删除或改为自然陈述。背后的叙事设计永远不露痕迹。

## 口径纪律（实战沉淀，不可破）

- **换表述不造假**：努力目标≠承诺；"需求验证与准入卡位"≠订单；"长期股权绑定机制"≠换股对赌细节；"战略协同份额"≠池子。
- **立项≠订单**：未签合同的需求/课题，只讲卡位价值，主动声明边界（展示诚实是加分项）。
- **敏感词反查清单**（定稿前 grep 零命中）：池子/干股/代持/缺口/个人薪酬/未决人名（如唐总、张部长）/工程指标明细（如 50Mbps/30ms/99.99%/25-50万）/内幕数字（如中C院/4000万）。
- **[待确认] 项**：要么省略，要么写死"（待确认）"，禁止推断变事实。
- **主线关联**：任何新业务叙事必须回答"跟泽天端侧算力+实时操作系统主线什么关系"。

## 交付格式（外发铁律）

Word（可编辑，python-docx：标题黑体/正文宋体 eastAsia 显式设置）+ PDF（fpdf2：中文字体 /System/Library/Fonts/STHeiti Medium.ttc；PDF 渲染须剥离 ** 标记）双份，放 ~/.hermes/cache/documents/。版本号管理：V1/V2 同目录保留可对比。

## 监工验证清单（交付前必过）

1. 两文件 size>0，docx 可 python-docx 重开（打印段落数），pdf 可 pymupdf 打开（页数+字符数）
2. 敏感词反查零命中
3. 内容抽查：核心口径字符串在正文（如"51%""49%""场景延伸"）
4. 仓库侧效应：涉及副官主线/人脉/待办的同步改动必须 commit+push（0/0 分叉）
