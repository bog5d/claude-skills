# 股权穿透图生成指南

## 数据采集优先级

1. **公告原文** — 巨潮资讯 + 深交所/上交所公告 + 权益变动报告书
2. **年报前十大股东** — 精确持股股数、持股比例、一致行动关系
3. **天眼查/企查查** — 股东企业的 GP/LP 结构、关联方
4. **新闻摘要** — 同花顺/网易财经，可用 web_search 精确匹配提取

## 穿透至少三层

- 第一层：直接持股股东（前十大）
- 第二层：持股平台/投资公司/合伙企业的出资结构
- 第三层：最终实际控制人（自然人/国资主体）

## 关键发现必须标注

- 一致行动协议到期时间
- 股权质押/冻结状态
- 控制权交易失败记录（时间线）
- 无实控人状态 + 形成原因
- 买方 SPV 的出资结构细节

## 交易事件链格式

```
202X.XX.XX  买方A 公告拟受让 XX%（X,XXX万股） 价格 ¥XX.XX
202X.XX.XX  交易所下发问询函
202X.XX.XX  公告放弃/终止/宣告失败 [原因：XXX]
202X.XX.XX  买方B 公告拟受让 XX%  ...
```

## 另一 AI 初步信息整合模式

当用户提供"另一 AI"（Cursor/Claude/其他）的初步分析时，工作流如下：

1. **不重复劳动**：另一 AI 已做的分析不用重做
2. **补充穿透**：另一 AI 通常不会做股权穿透图，这是 Hermes 的增值点
3. **标准化输出**：将散乱的初步分析组织为 7 模块 + 股权穿透图结构
4. **补充缺失模块**：另一 AI 通常漏掉合规记录、监管函、一致行动协议条款
5. **出 PDF**：使用 `delegate_task` + `fpdf2` 生成标准化报告
