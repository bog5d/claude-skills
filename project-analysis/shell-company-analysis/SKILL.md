# Shell Company Analysis — 壳公司借壳可行性评估框架

## 评估维度（7大模块）

### 模块一：财务排雷（6项标准化检查）

每项用 ✅⚠️❌ 标记，形成排雷速览表。

| # | 检查项 | 查看内容 | 数据来源 |
|---|--------|---------|---------|
| 1 | 审计意见 | 近三年审计报告是否为标准无保留 | 年报 |
| 2 | 经营现金流 | 是否为正、是否持续萎缩 | 现金流量表 |
| 3 | 净现比/盈利质量 | 净利润 vs 经营现金流匹配度 | 利润表+现金流量表 |
| 4 | 存贷双高/负债率 | 货币资金 vs 有息负债、资产负债率趋势 | 资产负债表 |
| 5 | 应收/存货 | 应收占营收比、存货减值风险 | 年报附注 |
| 6 | 信披/内控/股权雷 | 证监会处罚、交易所监管函、股权冻结、关联方资金占用、子公司失控 | 巨潮资讯、天眼查 |

排雷结论：🔴 极高风险 / 🟠 高风险 / 🟡 中等风险 / 🟢 低风险

### 模块二：商业模式与壁垒

**分析框架：**
- 主业拆解（产品线+营收占比+客户结构）
- 第二曲线（如有，评估真实性和进展）
- 壁垒分析（客户认证/技术/规模/牌照等）
- 弱点清单（行业周期/客户依赖/技术迭代等）

输出格式：✅ 优势 vs ❌ 弱点 对照表

### 模块三：核心财务数据

- 近三年营收、净利润、扣非净利润趋势
- 毛利率走势（判断竞争力和定价权）
- 资产负债率趋势
- 每股净资产变化（判断是否在缩水）

### 模块四：估值与股价

- 总市值、PE(TTM)、PB、PS
- 估值是否泡沫化（PB是否虚高、是否靠题材炒作）
- 流通市值 vs 总市值（是否全流通）

### 模块五：股权结构与控制权

- 实际控制人及持股比例
- 一致行动协议状态
- 股份质押/冻结/司法拍卖情况
- 近两年控制权变更尝试
- 大股东卖壳意愿判断

### 模块六：合规与监管记录

- 证监会处罚/立案调查（一旦有，壳价值归零）
- 交易所问询函/监管函频次
- 投资者索赔诉讼
- 关联交易/资金占用

### 模块七：壳质量综合评分

| 维度 | 权重 | 评分标准 |
|------|:---:|------|
| 合规干净度 | 30% | 有处罚=0分，有监管函=5分，干净=10分 |
| 资产干净度 | 15% | 负债率、商誉、对外担保 |
| 股权稳定性 | 15% | 质押/冻结/司法纠纷 |
| 市值合理性 | 20% | 15-30亿最佳 |
| 主业可处置性 | 10% | 原主业能否剥离 |
| 审核通过概率 | 10% | 板块、处罚史、监管态度 |

综合得分：___/10

### 最终评级

- 🟢 **适合**（≥7分）→ 可推进尽调
- 🟡 **待定**（5-7分）→ 有瑕疵但可谈
- 🔴 **不适合**（<5分）→ 放弃

## 执行流程

### Step 1: 信息采集

并行搜索（建议2个 delegate_task 子代理）：
- 子代理A：财务数据 + 公告 + 监管记录
- 子代理B：股权结构 + 新闻舆情 + 行业分析

数据源优先级：巨潮资讯 > 东方财富 > 同花顺 > 雪球 > 搜索引擎

### Step 2: 按7模块填表

逐模块输出检查结果，不打分先列事实。

### Step 3: 评分+评级

综合评分表 + 最终结论（一句话）。

### Step 4: 生成 PDF 报告

🚨 **波总要求：只出 PDF，不出 DOCX。**

使用 `delegate_task` 子代理生成 PDF。子代理用 `fpdf2` 库（`python-docx` 读取 DOCX + `fpdf2` 写入 PDF），这是最可靠的方案。排版标准：

- **标题**：黑体 18pt（`STHeiti` 或 `Hiragino Sans GB`）
- **小节标题**：黑体 13pt/15pt
- **正文**：宋体 11pt（`Songti SC`）
- **行距**：1.5 倍
- **关键数字**：加粗黑体
- **表格**：带颜色标记（绿/黄/红背景条，深色表头）
- **一票否决项**：红色警告框单独标注

> ⚠️ `fpdf2` 不支持 Unicode emoji（✅❌⚠️🔴🟡），需替换为 ASCII 等效符号（`[OK]` `[X]` `[!!]` `[HIGH]` `[MED]`）。

> ⚠️ `delegate_task` 生成大型报告可能超时（默认 600s）。如果超时，重试一次即可——第二次通常成功。不必重新搜索数据，直接复用已有数据重新生成。

### Step 5: 交付

报告结构：排雷速览 → 商业模式 → 财务 → 估值 → 股权 → 合规 → 评分 → 借壳路径（泽天视角）→ 风险清单 → 结论

最终文件路径：`/Users/mac/Downloads/<公司名>_壳资源评估报告.pdf`

## 关键风险信号（一票否决项）

以下任一命中，直接判 🔴 不适合：
1. 近三年有证监会行政处罚
2. 实控人股份被冻结/轮候冻结/司法拍卖无法解决
3. 连续两年亏损且净资产可能转负（ST风险）
4. 子公司失控/内控被出具否定意见
5. 审计意见为非标（保留意见/无法表示意见/否定意见）

## 波总专用背景（已固化）

**产业方**：航空航天+军工电子高科技企业，核心产品为纯国产实时操作系统（RTOS），军用航空航天细分赛道领先。
**上市策略**：Plan A = 独立IPO；Plan B = 壳资源托底。
**收购模式**：实控人+外部资金方联合体收购（非公司直接收购），实控人自有资金有限，需联合资金方共同出资。
**壳需求特征**：主板壳、30亿市值以下为佳、主业可剥离、合规干净。对价格敏感（联合体模式）。

## 陷阱

- 不要仅凭市值小就判断是好壳（可能是个雷壳）
- 负债率低≠壳干净（可能有表外担保/隐性负债）
- 审计意见必须亲自查——很多垃圾壳年报看起来"正常"但实际是非标
- 创业板的壳天然比主板/中小板更难过会——审核标准等同于 IPO，跨界并购审核极严
- 一致行动协议到期终止是巨大风险信号，不是小问题
- `delegate_task` 生成大型报告易超时——重试即可，第二次通常成功，不必重新搜索数据
- 实控人"留置调查"即使变更为"责令候查"也是一票否决——刑事调查信号，壳已被污染
- 司法冻结未披露原因是一票否决信号——比冻结本身更危险
- PDF 生成参考 `references/pdf-generation-macos.md`
