# 多维升级系统 — 升级规则 V2.0

## 背景

V1 升级规则仅依赖答题次数，导致"刷几局就升段"（如 6/17 一天从黄金 I→铂金 I）。修复方案将升级条件改为多维达标。

## 升级条件表

| 段位 | 覆盖率 | 抽样测试 | 正确率最低 | 错题攻克 | 平均掌握度 |
|------|--------|---------|-----------|---------|-----------|
| 青铜 | 0% | 不需要 | — | — | 0% |
| 白银 | ≥15% | 需要 | ≥50% | — | ≥30% |
| 黄金 | ≥30% | 需要 | ≥55% | ≤40 | ≥40% |
| 铂金 | ≥50% | 需要 | ≥60% | ≤30 | ≥50% |
| 钻石 | ≥70% | 需要 | ≥65% | ≤20 | ≥60% |
| 王者 | ≥90% | 需要 | ≥70% | ≤10 | ≥70% |

## 覆盖率计算

```
覆盖率 = 已练习过的核心词数 / 核心词总数
已练习 = review_count > 0 的核心词
```

## 平均掌握度

```
平均掌握度 = sum(所有核心词 mastery) / 核心词总数 × 100
```

## 降级机制

- **触发条件**：连续 2 次抽样测试正确率 < 60%
- **惩罚**：降回上一主段位最低 sub-rank
- **报告**：生成反骨史诗报告（最弱 10 词 + 行动建议）

## 阶段激活

| 阶段 | 激活条件 | 内容 |
|------|---------|------|
| Phase 2 句子理解 | 覆盖率≥30% | 例句填空 + 句子翻译 |
| Phase 3 阅读翻译 | 覆盖率≥50% | 阅读理解 + 翻译训练 |
| Phase 4 作文模板 | 覆盖率≥80% | 填空式作文训练 |

## 关键文件

- `bin/engine_upgrade_sample_descent.py` — 主引擎
- `data/rank_config.json` — 段位条件配置
- `bin/reset_rank.py` — 段位重置工具
- `data/_quiz.json` — 抽样测试结果存储
