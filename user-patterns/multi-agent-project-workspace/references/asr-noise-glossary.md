## 整理工作流
1. 通读原文一遍，只标不改
2. 先扫本表替换高置信项
3. 人名/数字/公司注册名一律 `【？】` + 待核实清单
4. 说话人归属：按"谁在讲融资策略 vs 谁在讲技术团队"重排标签，整理稿开头给角色推断表
5. 结构化输出：核心结论 → 论证 → 行动项 → 资源盘点 → 风险与未决问题
