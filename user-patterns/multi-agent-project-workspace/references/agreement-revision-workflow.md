# 技术转化创业公司·战略协议审读与改版工作流

> 实例：FY战略合作协议 v1.1 → v1.2（2026-08-23，上海交大临近空间项目）。适用于高校技术转化、联合创始人框架协议、投资条款清单类文档。

## 工作流五步
1. **全文逐段解析 docx**（python-docx 读 paragraphs；注意正文可能藏在表格里，`doc.tables` 一并扫）
2. **出审读报告**：核心结构速览表 → 与既有会议共识逐条对照（一致性✓/⚠️）→ 红旗清单按🔴🟡🟢分级 → 修改优先级 P0/P1/P2
3. **听波总的谈判意图再动手**——他定方向，你出文本
4. **生成双版本**：修订标记版（红删除线=删、蓝=增，给对手方看改动痕迹显诚意）+ 干净版（可打印签署）
5. **程序自检 + 哈希校验交付**（见下）

## 协议红旗检查清单（技术转化语境复用）
- 🔴 **代持国有高校股权** = 国资流失风险 + IPO审核一票否决项。正确表述："登记于学校指定载体名下+过渡性协助安排"——经济实质不变，字面拆雷
- 🔴 **公司给股东个人发"融资提成"** = 变相抽逃出资/利益输送，未来国资基金尽调必揪。改法：支付主体改为创始人个人承担，或"经股东会决议由公司承担"
- 🟡 **薪资阶梯写死数字** = 抬高对手方决策门槛（"还没干就要花好多钱"）
- 🟡 缺保护条款五件套：竞业限制 / IP专利清单附件 / 反稀释 / 僵局解决机制 / 本协议与章程冲突时财产性权利优先
- 🟡 停薪罚则未区分"因对方原因导致失败"的免责例外
- 🟢 文字层：重复编号、"其他约定"应改"附则"、中英标点混杂、多余分号

## 波总谈判哲学（改版时贯彻）
- **核心条款锁死自己的**（如乙方10%持股写明"任何调整须经双方书面一致同意"），其余全留弹性
- **降低对手方决策难度**：把前置成本条款改成成功后付费结构——股份定死 + 成功才有奖励（融资额2%）+ 待遇跟随制（"比照联合创始人及高管同等待遇"，不写具体数字）
- 改版话术效果："从谈条件变成请上船"

## python-docx 生成修订标记版技巧
```python
# 同一个段落构建器跑两遍，tracked=True 出标记版 / False 出干净版
def segs(n_text, o_text=None):
    return [(o_text,"del"),(n_text,"ins")] if tracked else [(n_text,"normal")]
# run级样式：del→红色RGBColor(0xCC,0,0)+font.strike=True；ins→蓝色RGBColor(0x00,0x33,0xCC)
```
- 自检断言脚本：回读docx检查关键词 存在/不存在（如"按月薪1万" not in full）
- ⚠️ **假阴性坑**：标记版里被删除线保留的旧文本会让"已删除"断言失败——必须按 run 检查 `r.font.strike` 再定性，不能只查字符串存在性
- 中文字体设置：`run._element.rPr.rFonts.set(qn("w:eastAsia"), "仿宋")`

## 交付纪律
- 归档命名沿用工作区规范：`03_<交付物>工程/协议文本/YYYYMMDD_ox_协议名vX.Y_版本类型.docx`
- 走 agent-exchange 上传时资产名必须 ASCII（中文放 release 标题），回读哈希一致才算交付完成
- 台账登记一行含全部改动摘要
