# 财务全景诊断框架

当波总要求「分析我的财务状况」「给我做诊断」「看看我怎么样」时，按以下结构输出。

## 一、财务画像

### 收入特征
- 收入通道（几个、各多少）
- 稳定性（脉冲型 vs 稳定型）
- 是否存在误解（如「银行流水¥46K含报销，不是纯工资」）

### 消费特征
- 总消费规模 + 笔数
- TOP3 分类占比（餐饮/交通/日用通常是前三）
- 关键判断：铺张还是可控？

### 债务结构
- 总负债 = 亲友 + 平台
- 有息占比 vs 无息占比
- 加权平均利率
- 年利息支出

## 二、现金流诊断

### 真实月现金流
```
收入:   ¥XX,XXX (分通道列出)
支出:
  固定: ¥X,XXX (社保/房租/话费/保险)
  生活: ¥X,XXX (近3月均)
  老婆: ¥X,XXX (养家+还卡)
  ──────────
  合计: ¥X,XXX
结余:  ¥X,XXX ✅/❌
```

关键判断：
- 结余为正数 → 健康
- 结余为负数 → 透支风险
- 注意老婆 ¥25K 是「总包」不是纯消费

## 三、趋势预测

### 第一阶段（短期行动）
本周内/月内的紧急事项（如清高息平台债）

### 第二阶段（中期还债）
月均可还 → 预计清债时间

### 里程碑路线
```
现在    ¥XXX,XXX
目标①  ¥XXX,XXX  ← 还需还¥XXK
目标②  ¥XXX,XXX  ← ...
Zero    ¥0        ← 预计20XX年
```

## 四、核心结论

✅ 健康面（3条左右）
⚠️ 风险面（2-3条）
🎯 第一优先级（1条，本周要做的）

## 输出原则

- **所有数字必须基于 debts.json / income.json / expenses.json 的实时数据**，不得用记忆中的旧值
- **如果波总修正了某个数字（如「月收入不是那个数，是40K」），立即修正并用修正值重算**
- **一个方案，不要给 ABC 选项** — 波总要的是结论，不是选择题
- 老婆的支出（¥25K/月）是「家庭总包」不是纯消费，单独标注
