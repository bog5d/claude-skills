# 债务转移模式 — 垫付逻辑详解

## 核心原则

**当债主A帮波总垫付给债主B → A的债权增加（amount += 垫付额）**

A多掏了钱出去，所以波总欠A的金额要加上这笔。这是最常见的逻辑混淆点。

## 正确 vs 错误

```
错误 ❌: 妈妈 ¥135,100 - ¥10,000(帮还二爸) = ¥125,100
   × 妈妈多掏了钱怎么还变少了？

正确 ✅: 妈妈 ¥135,100 + ¥10,000(垫付二爸) = ¥145,100
   ✓ 妈妈多掏了¥10K所以波总欠妈妈多了¥10K
```

## 净效果

```
二爸 -¥20,000（清零）
妈妈 +¥10,000（垫付部分）
波总自还 -¥10,000
────────────────
net: -¥10,000（只有自还部分减少了总负债）
```

## 2026-07-06 翻车复盘

波总说：「妈妈原本¥135,100 → 她帮我垫付了¥10K给二爸 → 变成¥145,100」

我（AI）理解反了，以为妈妈帮还=妈妈减少。导致：
- 妈妈金额错了（写¥135,100而不是¥145,100）
- 家庭总额错了（少¥10,000）
- HTML 显示错误数字，波总非常生气

**教训：垫付方金额增加，不是减少。**
