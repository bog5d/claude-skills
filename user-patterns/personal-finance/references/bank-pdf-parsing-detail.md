# 银行对账单 PDF 解析参考

> 2026-07-02 实测翻车记录。三种银行 PDF 格式各不相同，各自有坑。

## 一、农业银行（ABC）

**发件人**: abc-mobile-bank@abchina.com
**附件**: ZIP（AES-256加密），内含 PDF
**密码来源**: 手机短信（与银行确认短信同一条）
**解压**: 必须用 p7zip（Python zipfile 不支持 AES-256）

### PDF 格式

- 表头: `户名：王波 / 账户：6228484101670076415 / 起止日期：20260101-20260702`
- 列: `交易日期 | 交易时间 | 交易摘要 | 交易金额 | 本次余额 | 对手信息 | 日志号 | 交易渠道 | 交易附言`
- 金额: 带符号（+10000.00 / -1000.00）
- 无表头重复行（比招行干净）
- 附言含详细交易描述，格式如 `NA2026010905155216519793710210402相思椒餐饮（岳麓荣盛店）`

### 交易摘要归类

| 摘要 | 类别 | 
|------|------|
| 转存 | 收入（工资/备用金） |
| 微信支付 | 过路消费（已在 expenses.json） |
| 财付通 | 过路消费 + 零钱通转入 |
| 支付宝 | 过路消费 + 信贷还款 + 小荷包 |
| 跨行汇款 | 银行转账（Dily等） |
| 他行汇入 | 收入 |
| 程支付 | 携程金融还款 |
| 转支 | 银行转账支出 |

## 二、招商银行（CMB）

**发件人**: 95555@message.cmbchina.com
**附件**: ZIP（标准加密），内含 PDF
**密码来源**: 招商银行App → 流水打印 → 申请记录（与短信密码不同）
**解压**: 7z 或 Python zipfile 均可

### PDF 格式

- 16 页，中英双语排版
- 表头: `户名：王波 / 账户：6214********5398 / 申请时间：2026-07-02 10:51:27`
- 列: `记账日期 | 货币 | 交易金额 | 联机余额 | 交易摘要 | 对手信息`
- 金额: 带符号（-34.00 / +7026.30）
- **⚠️ 每页顶部重复表头行** — 解析时必须跳过含 `Date | Currency` 等 header 的行
- 表格跨页时中间页只有下半部分数据，无 header

### 交易摘要归类

| 摘要 | 类别 |
|------|------|
| 快捷支付 | 日常消费（滴滴/美团/携程） |
| 代发款项 | 工资（湖南泽天智航） |
| 转账汇款 | 账户间转账 |
| 银证转账 | 投资/理财 |
| 一网通支付鼓励金 | 小额返现（¥0.01~¥3）|

## 三、工商银行（ICBC）

**发件人**: webmaster@icbc.com.cn
**附件**: PDF 直接发送（无加密、无 ZIP）
**密码**: 无

### PDF 格式

- 6 页，首页顶部有二维码验真
- 表头: `卡号 6212262317000300695 / 户名：王波 / 起止日期：2025-07-02 — 2026-07-02`
- 列: `交易日期 | 时间 | 账号 | 储种 | 序号 | 币种 | 钞汇 | 摘要 | 地区 | 收入金额 | 支出金额 | 余额 | 对方户名 | 对方账号 | 渠道`
- **⚠️ 金额分两列**（不是带符号的单列！）— `收入金额` 列有值 = 正数，`支出金额` 列有值 = 负数
- 每行有完整对手账号（脱敏后如 `2155****0690`）

### 交易摘要归类

| 摘要 | 类别 |
|------|------|
| 微信零钱提现 | 收入（¥+，零钱→银行卡） |
| 消费 | 支付宝过路消费 |
| 跨行汇款 | 转账支出 |
| 他行汇入 | 他行转入 |
| 贷款本息 | 工行贷款还款 |
| 天天 | 天天基金销售 |

## 四、通用去重规则

银行 PDF 中大约 55-60% 的交易是「支付宝/微信过路消费」，这些已经存在于 expenses.json 中。

### 判断标准

1. **摘要含关键词**: `支付宝 / 财付通 / 微信支付 / 快捷支付` → 大概率已有
2. **对方含特定关键词**: `支付宝（中国）网络技术 / 财付通支付` → 过路
3. **精确匹配**: `日期 + 金额(±¥2) + 商户名前6位` → 匹配 expenses.json 的 `dedup_key`

### 不需要导入的

- 支付宝/微信过路消费（已存在）
- 王波账户间自转（不是消费或收入）
- 贷款本息自动扣款（非新增消费，是债务还款）

### 需要导入的

- 工资代发（湖南泽天智航电子技术有限公司）→ income.json
- 奖金 → income.json 的 bonus_extra 字段
- 他行汇入 → income.json 的 other_income
- 跨行汇款给 Dily（家务支出额外确认）
- 携程金融还款 → 核对 debts.json 是否有此债
