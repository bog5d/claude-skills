# 支付宝保险保单分析 — 提取与分类流程

## 概述

波总家庭保险全部通过支付宝蚂蚁保扣缴。`import_csv.py` 会跳过保险（归入理财/保险过滤），因此需要直接从原始 CSV 提取分析。

## 数据来源

支付宝 App → 我的 → 账单 → 右上角 `...` → 开具交易流水证明 → 选 12 个月 → 导出 ZIP（含密码）

## 提取流程

### Step 1: 解压（中文文件名编码处理）

```bash
# 支付宝 ZIP 可能因中文文件名导致 unzip 失败，用 Python：
python3 << 'PYEOF'
import zipfile, os
zip_path = '/path/to/支付宝交易明细.zip'
out_dir = '/tmp/alipay_full'
os.makedirs(out_dir, exist_ok=True)
with zipfile.ZipFile(zip_path, 'r') as zf:
    zf.setpassword(b'密码')
    zf.extractall(out_dir)
PYEOF
```

### Step 2: GBK → UTF-8 转码

```bash
# 找到 CSV 文件，支付宝导出为 GBK 编码
ls /tmp/alipay_full/*.csv
iconv -f GBK -t UTF-8 /tmp/alipay_full/支付宝交易明细\(日期\).csv > /tmp/alipay_utf8.csv
```

### Step 3: 提取保险交易

```bash
grep -i "保险" /tmp/alipay_utf8.csv > /tmp/insurance_only.csv
```

CSV 列：`交易时间,交易分类,交易对方,对方账号,商品说明,收/支,金额,收/付款方式,交易状态,交易订单号,商家订单号,备注`

### Step 4: 分组分析（按保单 + 被保险人）

```python
# 关键分组字段：商品说明
```

## 排除项

以下保险交易不纳入固定支出分析：
- 不计收支（如携程保险代理 ¥40 — 旅行险，非固定保单）
- 收入类（如退货宝补偿 ¥5.20 — 理赔退款）
- 一次性购买（如自动续保触发的新保单首期）
