## 使用方式

1. **LLM 清洗**：把本表完整贴进 Cursor 任务书"ASR 已知高频错误"段。
2. **ASR 热词**：取"正确"列全部词 + 高频变体 → Whisper `initial_prompt` 或云 API 热词表（上限内全放）。
3. **回填**：每批拆解后，把 Cursor 分析里新出现的"ASR 错字按对照表还原"之外的新变体追加进对应词条。
4. **验证**：波总确认过的更正优先；不确定的词条保持"正确写法 + [待确认]"。

## 注意

- 部分变体有歧义（如"九州"可能是九院也可能是九州集团），必须靠上下文判断，别机械替换。
- ASR 数字（金额/百分比/日期）错误无规律可循，一律标 [待确认]，不能靠词典。
