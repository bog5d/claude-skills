# 团队会议/路演转写稿诊断（Team Meeting Diagnostics）

波总的团队在外跑路演/投资机构拜访/高管尽调访谈，产出录音转写稿（常见为"智能规整"= 粗糙 ASR，错误率高）。波总本人常不在场，要的是**洞察**而非归档：
① 团队知识盲区（讲不透、需要波总补课的点）② 波总不知道的新信息 ③ 团队对外表述与既定口径不一致（口径雷）④ 团队对客户/投资人说了波总没拍板的事（承诺风险）。

## 铁律（波总明确要求）

1. **新任务类先给思路框架，确认后再动手**——波总会说"先说说思路""你能理解吗"。用"理解复述 + 分步管线 + 需要确认的输入"三段式回应，不要直接开干。
2. **拆解/清洗/分析主流程派 Cursor CLI**（`cursor-agent -p --yolo "$(cat /tmp/prompt_xxx.md)"` 后台跑 + notify_on_complete），Hermes 只做：解压/转格式、写任务书、验证产出、入库回填。
3. **禁止编造**：ASR 无法确认的人名/机构/数字一律标 `[待确认]`，绝不猜测成事实；引用必须带原文摘录。
4. 转写稿是粗糙 ASR 时，先喂已知错误变体对照表（见 references/asr-lexicon.md），清洗质量立升。

## 处理管线（5 步）

1. **输入盘点**：解压看内容（音频 or 已转写稿？场景类型？）。docx 转 txt 用 python-docx 批量转换（terminal 跑，勿用 execute_code——环境可能拦截）；批量稿总文本量 30 万字符级，勿自己全读。
2. **术语库注入**：读 references/asr-lexicon.md，把已知 ASR 错误变体写进 Cursor 任务书。
3. **Cursor 派活**：用 templates/cursor-diagnosis-prompt.md 模板写任务书（含：文件路径列表、公司背景、既定口径对照表、每份输出结构、汇总报告结构、铁律）。后台 `cursor-agent -p --yolo` 启动。
4. **验证**：抽查 1-2 份分析文件（重点抓"口径偏差"表的犀利度和 [待确认] 标注纪律），确认质量后等汇总。
5. **回填入库**：高置信新信息写拆解卡/实体索引（仓库协议：原始素材→清洗稿→SRC-拆解卡→validate→commit+push）；新发现的 ASR 错误变体回填 references/asr-lexicon.md。

## 五维对齐体检（每份转写稿的分析框架）

对每份文件输出 md（结构见模板），核心五维：
1. **会议信息**：机构名、场景（路演/拜访/尽调/访谈）、我方/对方出席人（按说话人内容推测身份+置信度）
2. **说话人识别**：每人编号+推测身份+置信度+依据原文摘录
3. **新增信息**（波总不知道的）：一句话一条，敏感项标 [待确认]/[已对照确认]，说明重要性
4. **口径偏差**：团队表述 vs 既定口径对照表，逐条列差异（原文摘录+问题说明）——**波总自己现场的"两套数""未拍板数字说成现在时""总部说错"是最高价值雷**
5. **承诺与风险**：团队说了公司没拍板的事、时间表、数字、条件；敏感信息泄露
6. **待波总确认**：每份最多 5 个需波总回答/决策的问题

汇总报告：横向共性问题（系统性>个例）→ 团队能力画像 → 需波总补位前 5 件事 → 信息补全清单 → 与战略主线的未对齐点 → 建议动作。

## ASR 术语库飞轮（让转写越转越准）

- 每批拆解挖出的错误变体 → 回填 references/asr-lexicon.md（正确写法↔错误变体映射）
- 术语库可注入 ASR 引擎热词（Whisper large-v3 initial_prompt / 云 API 热词表）——换掉不吃热词的"智能规整"是提升空间最大的单点
- 波总/团队确认过的更正 → 回填术语库（人的纠错是最强监督信号）
- 每批统计错误率/错误类型分布，月度看曲线

## 交付格式

- 每份分析 + 汇总报告为 md（analysis/ 目录）
- 波总要外发/汇报时：Word+PDF 双份（python-docx 中文字体用 STHeiti，fpdf2 PDF 用 /System/Library/Fonts/STHeiti Medium.ttc），输出到 ~/.hermes/cache/documents/
- 汇报要点直接 Telegram 精炼呈现，先报进度再报发现

## 支持文件

- `references/asr-lexicon.md` — 泽天体系 ASR 错误变体对照表 + 术语库维护方法
- `templates/cursor-diagnosis-prompt.md` — Cursor 拆解任务书模板（复制修改即用）
