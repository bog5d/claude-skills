## 课程映射（为什么这么设计）

- 维护频率 ← 155 圈：命友=有事没事都联系；密友50=≥1次/周创造价值；好友100=≥1次/月节日必联系。
- 24小时复联 ← 「24小时再联络」（三个方法留积极印象）。
- 给予/求助 ← 3:2 原则（BNI 付出者收获：帮3次求2次）。
- 引荐 ← 引荐即社会资本核心流通物（答案/交易/机会/信息/影响力/引荐）。
- 风险边界/休眠 ← 修剪人脉 3 原则（除旧迎新保健康）。
