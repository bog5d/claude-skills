# 说话人身份确认闭环（2026-08-12 SRC-20260812-001 实战校准）

波总明确要求：处理录音转写时"如果不确认（说话人）是谁，就跟我确认；**跟我确认的时候，一定要说他说了什么话**；语音转文字有错误的，要适度地提炼、适度地推测提炼"。

## 流程

1. **入库先行**：raw → clean（含说话人映射表：推测身份/依据/置信度/用户确认列）→ 拆解卡 → 台账/待办/日程/实体增量。
2. **确认请求**：逐人列出「推测身份 + 依据 + 原话摘录（关键句 verbatim）」，再问是谁。禁止只问"说话人1是谁"。
3. **用户回复**（如"①=江XX ②=张雨竹"）→ 回写全部受影响文件。
4. **回写清单**（同"用户更正人名→全模块传播协议"）：
   - clean 稿映射表"用户确认"列 → 是/姓名；未知扫描/AI 推测行改 `[已确认]`
   - entities.md：确认者加别名（如"说话人3（SRC-xxx）"）+ last_updated；独立待确认条目（PER-xxx）备注改"已确认=某人"或并入已有实体
   - 处理台账"待确认/缺口"列移除已确认项
   - OPEN.md 相关"核实说话人身份"待办归档 DONE（原子化：同一次编辑删 OPEN 行 + 追加 DONE）
   - 工作日志当日行更新
   - relations.md：新增/更新任职关系（person→org，带 source+confidence）；原"身份待确认"条目置信度 低→高（实测：PER-041 说话人4 低 → PER-041 蒲田 高）
   - 有联系方式的确认者建人脉卡 `人脉管理/<姓名>.md`（全息背景卡格式：联系方式+互动记录+下一步动作），并同步 `人脉管理/README.md` 总表行 + 总人数/亲密度统计（实测 24→27）
   - 已有人物合并用别名指向式样 `=张远（PER-002）`，不新建重复条目
5. 全程 `_raw.md` 正文不动（溯源链完整）。

## 对话内直接称呼证据法（最高置信度技巧）

- 波总 00:11:46 喊"江总，袁明兄需要投屏吗？" → 00:11:54 说话人5 应答"不用，我先把情况跟你说一下" → **说话人5=江总**（注意：不是被"请介绍产品"的另一人，应答投屏问题的才是）。
- 对方称"我想请教一下王总" + 答问全是泽天融资/实缴/国资条款 → 说话人3=波总。
- 自称"我们是产投旗下的科创投，就在楼上" → 单位锁定，剩姓名。
- 末尾称呼互换："好，张总"（波总对科创投）→ 科创投对接人姓张，与"张雨竹已调天使部"等已知人事交叉核对。
- 用第三人称介绍某人的说话人 ≠ 该人（路演人讲"我们的吴总/王总"→ 路演人非吴总非波总）。

## 实战案例（SRC-20260812-001）

5 位说话人：2 位高置信度锁定（波总=被称王总；说话人5=江总=被波总直接喊名），2 位单位锁定待姓名（路演人=泽天方；科创投张总），1 方（成都中小担）参会但无独立发言——确认请求里要明说"全程没识别到独立发言，是没说话还是转写漏了"。

**确认结果（用户一次回复全部认领）**：说话人1=宋佳莹（泽天路演）、2=张晓嵩（科创投）、4=吴琛亮（华西证券）、5=江元明（华西证券产业金融中心，15828425210）；同时认领旧素材——华西会说话人3=张远（与浙商会说话人1 同一人）、说话人4=蒲田（投行总部投行业务岗 18302880622）、说话人6=刘贝蓓（四川根据地战略委员会主任委员 15680688369）；浙商会说话人3 定为"疑为行长随从、不再追认"。

## 陷阱

- 用户附带的 AI 摘要（"以上由AI大模型生成，可能包含不准确的信息"）不作事实；入库放 raw 引用块并标注。
- ASR 变体统一（如 王小松/王晓聪/小松总→王晓松；杨强明/乔品总→杨乔敏）时在 entities aliases 列留全变体，别丢（后续声纹/搜索还要用）。
- 确认请求一次列全所有未确认者（新旧素材的一起列），不要挤牙膏式逐个问。
- 有下一位确认者可能是同一个人（如华西会说话人3 与浙商会说话人3 是否同一人）→ 明确写出"是否同一人待确认"，用户一句"是张远"同时解决两个 ID。
- 用户可能给"不用管"定案（"浙商会说话人3 可能是浙商银行行长随从，没加微信，不管"）——同样要回写归档：entities 备注改"疑为行长随从，不再追认（用户定案）"，OPEN 核实待办原子化归档 DONE 并注明定案，不留悬案。
- 确认结果跨素材联动：用户说"华西会的说话人三是浙商银行的张远"同时解决 PER-040（说话人3 002）=PER-002（张远）=浙商会说话人1 三个 ID，回写时把同人在所有素材里的别名/条目一并合并，勿只改一处。
