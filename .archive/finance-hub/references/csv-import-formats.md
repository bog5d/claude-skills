# 支付宝/微信 CSV 流水格式参考

## 支付宝导出格式

典型列头（UTF-8 BOM + CSV）：
```
交易时间,交易对方,商品说明,收/支,金额,收/付款方式,交易状态,交易订单号,商家订单号,备注
```

示例行：
```
2026-06-05 12:55:00,成都市明红蹄花,扫二维码付款,支出,325.00,花呗,交易成功,20260605xxx,, 
2026-06-06 09:30:00,余额宝,余额宝-单笔转入,收入,5000.00,,成功,,, 
2026-06-06 22:24:00,铁路12306,退款-火车票,收入,40.00,,退款成功,,,
```

关键字段：
- `交易时间`: 格式 `YYYY-MM-DD HH:MM:SS` 或 `YYYY/MM/DD HH:MM:SS`
- `收/支`: "支出" / "收入" / "不计收支"
- `金额`: 纯数字（正数），配合收/支判断方向
- `商品说明`: 有时包含退款标记

需要跳过的：
- `收/支=收入` 的行
- `商品说明` 含 "余额宝转入/转出/余利宝/基金/理财/保险/信用卡还款/花呗还款"
- `交易状态` 含 "退款中/处理中/失败"

## 微信导出格式

典型列头（UTF-8 BOM + CSV）：
```
交易时间,交易类型,交易对方,商品,收/支,金额(元),支付方式,当前状态,交易单号,商户单号
```

示例行：
```
2026-06-05 12:55,商户消费,成都市明红蹄花,餐饮,支出,¥325.00,零钱,支付成功,xxx,,
2026-06-06 11:20,转账,冷秀芳,,收入,¥2.00,零钱,已到账,,,
2026-06-06 09:39,零钱提现,工商银行,,支出,¥15522.38,,提现成功,,,
2026-06-01 15:25,转账,李杰（主号）,,支出,¥600.00,零钱,已到账,,,
```

关键字段：
- `交易时间`: 格式 `YYYY-MM-DD HH:MM`
- `交易类型`: "商户消费" / "转账" / "红包" / "零钱提现" / "充值" / "退款"
- `收/支`: "支出" / "收入"
- `金额(元)`: 可能带 `¥` 前缀

需要跳过的：
- `收/支=收入` 的行
- `交易类型` 为 "转账/红包/群收款/零钱提现/充值/信用卡还款/理财通/微粒贷"
- `当前状态` 含 "退款中/处理中/失败"

保留的（消费）：
- `交易类型=商户消费` → 正常消费
- `交易类型=扫码付款` → 正常消费
- `交易类型=退款` → 冲抵（标记 is_refund=true）

## import_csv.py 使用

```bash
# 预览（不入库）
python3 scripts/import_csv.py alipay_202606.csv --dry-run

# 正式导入
python3 scripts/import_csv.py alipay_202606.csv
# 输出: {"platform":"支付宝","parsed":85,"skipped":42,"added":85,"duplicates":0,...}
```

## 去重逻辑

去重 key = `{日期}_{金额取整}_{商户名前6字}_{来源平台}`

例如：
- `2026-06-05_325_成都市明_支付宝` 
- 同一笔消费微信+支付宝两边都有的 → 来源不同 → key 不同 → 不冲突（保留两份，标记来源）
