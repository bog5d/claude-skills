# A-Share Control Acquisition SPV Structuring Playbook

参考案例：神力股份（603819.SH）2025年控制权收购谈判。

## 典型场景

产业方创始人（新实控人）资金不足，引入外部出资人+配资机构，通过 SPV 收购上市公司控制权。

## 标准 SPV 架构（有限合伙）

```
GP：新实控人控制的有限公司（出资极少，承担无限责任，享有管理权）
LP-A（优先级/配资层）：机构配资/银行并购贷款 → 固定年化6-8%
LP-B（夹层/收益层）：个人出资人 → 固定8-10% + 超额分成20-30%
LP-C（劣后/权益层）：新实控人本人 → 剩余全部（第一亏损承担者）
```

## 为什么有限合伙 vs 有限公司？

| 维度 | 有限合伙 | 有限公司 |
|------|:--:|:--:|
| 税务 | 先分后税，不双重征税 | 企业25%+分红20%个税 |
| LP退出 | 转让LP份额即可 | 股权转让程序繁琐 |
| 分配灵活性 | 可自由约定waterfall | 严格按持股比例 |
| A股案例 | 主流选择 | 较少 |

**结论**：有限合伙是标准选择。

## 收益分配 Waterfall（标准顺序）

1. 返还本金（优先→夹层→劣后，按顺序）
2. 优先级固定回报（年化6-8%）
3. 夹层固定回报（年化8-10%）
4. 门槛回报率以上超额收益：
   - GP（新实控人）：20%（行业标准carry）
   - LP-B（出资人）：20-30%
   - LP-C（新实控人）：50-60%

## 出资人退出三条路径

| 路径 | 机制 | 锁定期影响 |
|------|------|:--:|
| GP回购 | 新实控人承诺N年后回购出资人LP份额 | **无影响**（不涉及上市公司股份） |
| 股利分配 | 上市公司分红→SPV→按waterfall分配 | **无影响**（分红不受限） |
| SPV减持 | 锁定期满后SPV卖股，资金分配给LP | 需等18个月 |

## 出资人6大核心条款

1. **保底回报**：年化8-10%，按季度累积
2. **GP回购承诺**：3年后或锁定期满，新实控人有义务回购LP份额
3. **超额收益分成**：门槛回报率以上部分，出资人分20-30%
4. **差额补足**：SPV持股价值低于本金+最低回报时，新实控人补足
5. **信息权**：每季度查看SPV财务和公司经营数据
6. **回售权（put option）**：股价持续低迷时，出资人可要求提前回购

## 谈判三板斧

1. 利益算给他看：保底+超额，3年翻倍拿多少，翻三倍拿多少
2. 锁定不锁你：GP回购承诺，跟股票锁定期无关
3. 安全有兜底：差额补足+个人担保

## 行业公允标准

- 配资机构（优先LP）：年化6-8%
- 夹层资金（出资人）：年化8-12% + 超额15-25%
- GP业绩报酬：超额利润的20%（PE行业标准）
- 劣后投资（新实控人）：剩余全部

## 关键法规（2025年5月修订）

- 协议转让取得控制权：收购人锁定**18个月**
- 协议转让5%以上非控制权：锁定**6个月**
- 私募基金投资标的资产满48个月：锁定**6-12个月**
- 实控人变更后36个月重组上市窗口不变
