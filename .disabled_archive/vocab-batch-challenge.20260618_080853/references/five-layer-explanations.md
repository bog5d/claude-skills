# 5-Layer Explanation Reference

These are the actual explanations that worked well in the 2026-05-26 batch session (4/6 correct). Use them as quality templates for future explanations.

Each explanation must cover all 5 layers, regardless of whether the user got the word correct or not.

## Layer Structure

1. **词根拆解 + 同源族** — Break down prefix/root/suffix, list 3-5 cognates
2. **演化链** — Trace evolution: Latin → Old French → Middle English → Modern English, with literal meaning
3. **视觉锚点** — One vivid image/metaphor that encodes the meaning
4. **原卡时空背景** — Extract from `original_anki_content` field if available (look for "时空坐标" or "波总原声" markers)
5. **考研锚** — Specific exam usage: collocations,辨析, reading comprehension patterns

## Model Explanations (from this session)

### recover /rɪˈkʌvər/ — ✅

① 词根: re-（重新）+ cover（覆盖）→ 重新覆盖 → 恢复。同源: recovery, discover, uncover
② 演化: 拉丁 recuperare → 古法 recovrer → 中英 recoveren。字面"重新盖回来"
③ 视觉: 🗄️ 回收站图标 — Ctrl+Z
④ 时空背景: （新词，等待 Anki 补录）
⑤ 考研: recover from 高频；辨析 recover(主动)/restore(被动)/revive(复活)

### digital /ˈdɪdʒɪtl/ — ✅

① 词根: digit（手指/数字，拉丁 digitus）+ -al → 用手指数的 → 数字的。同源: digit, digitate
② 演化: 拉丁 digitalis ← digitus → 掰手指计数 → 二进制 → 数码时代
③ 视觉: 🔢 手指泛着 0/1 二进制光芒
④ 时空背景: （新词）
⑤ 考研: digital economy/digital divide 热点必背；与 analog 对立

### pattern /ˈpætərn/ — ✅

① 词根: patron（模型，拉丁 patronus）变体 → 模式。同源: patron, paternal
② 演化: 中古 patron → pattern（音变）。原义"父亲的样子"→"照这个做"→ 模式
③ 视觉: 🧩 拼图模板凹槽决定每块位置
④ 时空背景: （新词）
⑤ 考研: behavioral pattern/pattern recognition 高频；比 mode 更偏"重复规律"

### react /riˈækt/ — ✅

① 词根: re-（回）+ act（做）→ 回头反应。同源: action, interact, counteract
② 演化: 拉丁 reagere ← re- + agere → 物理学"反作用力"→ 心理/化学
③ 视觉: 🧪 钠丢水里剧烈冒泡
④ 时空背景: （新词）
⑤ 考研: react to vs respond to 辨析；react 即时生理，respond 经思考

### gamble /ˈɡæmbl/ — ❌ (user: "不知道")

① 词根: 古英语 gamen（游戏）+ -le（反复）→ 一次次玩游戏 → 赌博。同源: game, gambol
② 演化: gamenian → gamben → gamble。从"玩耍"窄化为"赌上东西的玩耍"
③ 视觉: 🎰 老虎机拉杆
④ 时空背景: （新词）
⑤ 考研: gamble on 替代 risk；带"不计后果"负面色彩，比 bet 更文学

### deceive /dɪˈsiːv/ — ❌ (user: "终端")

① 词根: de-（离开）+ ceive（拿取，拉丁 capere）→ 把人带离真相 → 欺骗。同源: deception, receive, conceive, perceive
② 演化: 拉丁 decipere ← de- + capere → 古法 decevoir → deceive。"把人从真相那拿开"
③ 视觉: 🪞 哈哈镜 — 看到的不是真的
④ 时空背景: （新词）
⑤ 考研: deceive sb into doing 高频；deceive(隐瞒真相)/cheat(作弊)/trick(恶作剧) 辨析

## Quality Checklist

- [ ] Each layer is 1-3 concise lines, not paragraphs
- [ ] Cognates listed are real words the user will encounter
- [ ] Visual anchor is concrete and memorable, not abstract
- [ ] 考研 anchor cites specific collocations or reading patterns
- [ ] Wrong answers get an extra diagnostic note explaining WHY the user's answer was wrong (e.g. "你可能把 deceive 和 device/terminal 搞混了")
- [ ] Correct answers still get full 5-layer treatment — never skip layers for correct words
