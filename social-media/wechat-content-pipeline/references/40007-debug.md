# 微信 draft/add 40007 错误排查

## 症状
POST `cgi-bin/draft/add` 返回 `errcode: 40007, errmsg: invalid media_id`

## 根因
`thumb_media_id` 是必填字段，但提供的 media_id 无效。常见原因：
1. media_id 为空字符串或未传
2. media_id 来自其他公众号（跨账号）
3. media_id 对应的素材已过期或被删除
4. 外部上传的图片（picsum 等）被微信素材库拒绝

## 解决方案（2026-06-18 验证）
1. 用 `batchget_material` 列出公众号已有素材
2. 取第一个 `media_id` 作为 `thumb_media_id`
3. 确保 content 不为空（微信不接受空正文）

## 完整测试用例
```python
# 最小成功请求
data = {
    "articles": [{
        "title": "测试",
        "content": '<div data-role="paragraph"><p>测试文章</p></div>',
        "thumb_media_id": "从batchget_material获取"
    }]
}
```
